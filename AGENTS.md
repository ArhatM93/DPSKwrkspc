# Инструкции для этого каталога

Область действия: `D:\Files\DPSKwrkspc` и всё внутри него.

## Язык общения

- Общайся с пользователем **по-русски** во всех ответах в этом каталоге:
  пояснения, итоги, планы, вопросы, сообщения об ошибках и предложения.
- Правило действует постоянно, пока пользователь явно не попросит общаться
  на другом языке.
- Технические артефакты не переводятся: имена файлов и путей, команды,
  фрагменты кода, вывод программ, названия пакетов, флагов и API — приводятся
  как есть.
- Если ответ содержит длинный технический вывод, русским текстом оформляются
  пояснения вокруг него, а не сам вывод.

Чтобы отменить правило, достаточно удалить этот файл или попросить об этом
пользователя напрямую — прямой запрос пользователя имеет приоритет над этим
файлом.
